2. Server-Side Backend API (Node.js & FastAPI) Server Active
Match OrchestrationEndpoint
src/app/api/match/route.ts
POST /api/match - Full server-side pipeline: validates inputs, queries HF model, filters hurdle return, ranks, and allocates.
Opportunities APIEndpoint
src/app/api/opportunities/route.ts
GET /api/opportunities - Serves sanitized synthetic listings with status and minTicket filtering for consumers.
Model Status APIEndpoint
src/app/api/model/status/route.ts
GET /api/model/status - Tests HF endpoint health, measures ping latency, and returns safe service metadata.
Prediction APIEndpoint
src/app/api/predict/route.ts
POST /api/predict - Validates single applicant profile and executes model adapter inference with timeout.
FastAPI BackendPython Ref
backend/main.py
Standalone Python FastAPI implementation providing the exact same contract with Pydantic validation.
3. Model Adapter & ML Inference Pipeline ML Pipeline
HF Model AdapterAdapter
src/lib/model-adapter.ts
Hosted adapter with strict validation, 8000ms AbortController timeout, in-memory caching, and provenance tagging.
Hugging Face Space APILive Model
jensbender-loan-default...hf.space
Verified hosted scikit-learn Random Forest pipeline trained on 252k loan records; returns default probabilities.
In-Memory CacheCache
src/lib/model-adapter.ts (Cache)
TTL-bounded cache keyed by applicant profile feature hash to eliminate redundant upstream inference requests.
4. Financial Engine, Ranking, & Allocation (Pure Core) Pure TypeScript
Eligibility FilterModule
src/lib/eligibility.ts
Filters opportunities requiring open status, capacity > 0, budget >= minTicket, and non-corrupt risk inputs.
Finance FormulasModule
src/lib/finance.ts
Simple interest expected payout, profit, ROI, clamp return score, safety score, and risk-weighted match scoring.
Allocation EngineModule
src/lib/allocation.ts
Deterministic greedy allocation capping recommendations at Top 5, respecting per-opportunity capacity and total budget.
Synthetic DatasetData Store
src/lib/data.ts
12 deterministic records with distinct loan terms and verified applicant demographic features.
